# Canvas Paint Pro — All-in-One Studio Suite (Complete 61 Tools)

Canvas Paint Pro unites **MS Paint**, **Adobe Photoshop**, **Canva**, **Microsoft Word**, **Microsoft Excel**, and **Microsoft PowerPoint** into a single high-performance web studio.

---

## 🛠️ Complete 61 Tools Breakdown

### 🎨 1. MS Paint Tools (Basic & Advanced Drawing)
1. **Pencil Tool**: Pixel-level drawing (1px to custom stroke size).
2. **Brush Tool**: 6 specialized brush engines:
   - *Standard Antialiased Brush*
   - *Oil Brush* (multi-bristle textured simulation)
   - *Watercolor* (wet edge bleeding & transparency)
   - *Airbrush* (particle scatter spray)
   - *Calligraphy* (angled chisel stroke)
   - *Highlighter Marker* (semi-transparent flat stroke)
3. **Eraser Tool**: Adjustable size with `destination-out` transparency erasure.
4. **Fill Bucket / Flood Fill**: 32-bit `Uint32Array` Breadth-First-Search (BFS) flood fill with color tolerance slider.
5. **Color Picker / Eyedropper**: Pure composite canvas pixel sampling.
6. **Extended Shapes Library**:
   - Straight Line
   - Bezier Curve
   - Rectangle
   - Rounded Rectangle
   - Ellipse / Circle
   - Hexagon Polygon
   - 5-Point Star
   - Arrow
   - Speech Bubble
7. **Magnifier / Zoom Tool**: In, Out, Reset 100%, Pan (Hand tool or Spacebar+Drag).
8. **Canvas Crop & Resize Handles**: Real-time canvas dimension adjustment modal with presets (HD, 1080p, Classic 800x600, Instagram, Social Card, A4 Print).

---

### 🔮 2. Adobe Photoshop Tools (Advanced Raster Processing)
9. **Rectangular Marquee Selection**: Bounding box pixel selection.
10. **Elliptical Marquee Selection**: Circular / elliptical pixel selection.
11. **Freehand Lasso Tool**: Smooth freeform marquee.
12. **Polygonal Lasso Tool**: Point-to-point geometric selection.
13. **Magnetic Lasso Tool**: Automatic edge-snapping high-contrast lasso.
14. **Quick Selection Tool**: Brush-based area selection that expands into similar colored pixels.
15. **Magic Wand Tool**: Single-click color segment selection with adjustable tolerance & contiguous toggle.
16. **Move & Free Transform Tool**: 8 resize anchor handles, rotation arm/handle, scale, and commit.
17. **Clone Stamp Tool**: `Alt + Click` to set source pixel origin, paint to duplicate.
18. **Pattern Stamp Tool**: Integrated through preset pattern texture fills.
19. **Spot Healing Brush Tool**: Perimeter pixel blending for instant blemish removal.
20. **Healing Brush Tool**: Texture source blending.
21. **Dodge Tool**: Localized radial lightening.
22. **Burn Tool**: Localized radial darkening.
23. **Blur Retouch Tool**: Localized brush box blur.
24. **Sharpen Retouch Tool**: Localized unsharp masking.
25. **Smudge Tool**: Drag and smear pixels along cursor trajectory.
26. **Gradient Tool**: Interactive 2-color Linear and Radial gradients.
27. **Layer System**: Add layer, duplicate, delete, reorder up/down, merge down, flatten.
28. **Layer Blend Modes**: 16 blend modes (`Normal`, `Multiply`, `Screen`, `Overlay`, `Soft Light`, `Darken`, `Lighten`, `Difference`, etc.).
29. **Layer Opacity Slider & Visibility Toggle**: Real-time per-layer opacity & eye visibility toggles.
30. **Layer Masking & Clipping Masks**: Dedicated white/black layer masks & clipping mask toggling (`↳`).
31. **Image Filters**: Brightness/Contrast, Exposure, Hue/Saturation, Gaussian Blur, Sharpen, Find Edges, Emboss, Grayscale, Invert, Sepia, Vignette, Pixelate.

---

### 🎨 3. Canva Tools (Vector Design & Smart Layout)
32. **Drag-and-Drop Graphic Asset Library**: Categorized stickers, emojis, badges, and marketing arrows.
33. **Smart Alignment Guides & Snapping**: Real-time red alignment lines indicating horizontal & vertical centers.
34. **Image Frame Masks**: One-click crop of layer photos inside Circle, Heart, and Star frames.
35. **One-Click Background Remover Tool**: Automatic color-difference alpha threshold background eraser.
36. **Drop Shadow, Outline & Inner Glow**: Customizable styling on vector elements.
37. **Color Palette Extractor & Swatches**: Generates dominant color swatches directly from canvas artwork.
38. **Template & Preset Layout Switcher**: HD, 1080p, Instagram, Social Card, A4.

---

### 📝 4. MS Word Tools (Rich Text & Typography)
39. **Rich Text Formatting**: Font Family (Inter, Roboto, Playfair Display, JetBrains Mono, Pacifico, Impact), Font Size, Bold, Italic, Underline, Strikethrough.
40. **Text Alignment**: Left, Center, Right.
41. **Subscript & Superscript**: Typography sizing.
42. **Text Color & Highlight Color**: Dedicated swatch color selection.
43. **Curved Text & Text Effects**: Arc / circular path curvature toggle.
44. **Bulleted & Numbered Lists**: Formatted multi-line text blocks.
45. **Line Spacing & Letter Spacing Controls**: Dynamic kerning adjustments.
46. **Floating Text Box Insertion**: Freely resizable, draggable, rotatable text boxes.
47. **Find and Replace Tool**: Dialog searching through all document text elements.
48. **Word & Character Counter**: Real-time word and character statistics in status bar.

---

### 📊 5. MS Excel Tools (Spreadsheets & Charts)
49. **Dynamic Table / Data Grid Insertion**: Interactive table generator with customizable columns and rows.
50. **Cell Data Formatting**: Text, Numbers, Currency (`$1,200.00`), and Percentages (`45.0%`).
51. **Formula Engine**: Evaluates `=SUM(range)`, `=AVERAGE(range)`, `=MIN(range)`, `=MAX(range)`, `=COUNT(range)`.
52. **Table Styling**: Corporate Blue, Emerald Green, Dark Obsidian, and Warm Amber themes.
53. **Chart Generator**:
   - Bar Chart (with vertical gradient bars, labels, and auto-scaled grid axes)
   - Line Chart (with filled gradient area and discrete data points)
   - Pie Chart (with color-coded slices and percentage legend)
   - Doughnut Chart (with clean central cutout)

---

### 📽️ 6. PowerPoint Tools (Presentation & Slides)
54. **Multi-Slide Manager**: Slide deck tray with Add Slide, Duplicate, Delete, Reorder.
55. **Slide Canvas Presets**: 16:9 Widescreen (1080p) and 4:3 Standard.
56. **Object Animations**: Fade, Fly-In, Zoom, and Bounce transitions.
57. **Full-Screen Presentation Mode**: High-res slide show player (`F5`) with arrow key navigation.

---

### 💾 7. System, Export & Print Tools
58. **Global Undo / Redo History Stack**: Photoshop-style action history list (`Ctrl+Z` / `Ctrl+Y`).
59. **Export Formats**:
   - PNG (1x, 2x Retina, 4x Ultra 4K/8K)
   - JPEG (adjustable quality)
   - WebP (modern web compression)
   - SVG (vector embedding)
   - Multi-Page PDF (compiles all presentation slides into a printable PDF document)
60. **Raw Project Save/Load (.JSON format)**: Preserves layers, blend modes, vector objects, and slides.
61. **High-Resolution Print Engine**: Native `window.print()` with page preview and print CSS layout.
